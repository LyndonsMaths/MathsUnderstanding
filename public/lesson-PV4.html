Make Number Patterns (Counting in Steps)

PV4 · Numbers to 1,000,000 · NZ Year 6

A number pattern counts up or down by the same amount each time
The amount you add or subtract each time is called the step size (or common difference). Once you find the step, you can find any missing number in the sequence.

How to find the step size — subtract two neighbours
To find the step, subtract any number from the one that comes after it.
Then decide: is the sequence going up (adding) or down (subtracting)?
The 3-step method
Step 1: Pick two neighbours and subtract: 124,400 − 123,400 = 1,000
Step 2: Check direction — numbers getting bigger = count up
Step 3: Add the step to the last known number: 125,400 + 1,000 = 126,400 ✓

"X more/less than Y" — adding or subtracting one step
Some questions give you a single starting number and tell you to count one step up or down. These look different but work the same way — just add or subtract the given amount.
"What number is exactly 10,000 less than 503,000?"
503,000
−10,000
493,000
503,000 − 10,000 = 493,000 ✓
Check using place value: the ten-thousands digit changes from 0 → 9 (we borrowed from hundreds-thousands)
Tip: use the place value table to check your work
When you add or subtract a step like 10,000, only the ten-thousands column changes (or triggers a carry/borrow). All other columns stay the same unless there's regrouping.
Backwards sequences — same method, subtract instead
A decreasing (going down) sequence still has a regular step — but you subtract each time. Watch for the step being larger, like counting down by 10,000.
