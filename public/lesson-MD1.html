Multiply Whole Numbers

MD1 · Multiplication & Division · NZ Year 6

Three types of multiplication
In Year 6 you need to multiply using a written column method for three different situations:

Type 1: 3-digit × 1-digit (e.g. 345 × 6)
Type 2: 4-digit × 1-digit (e.g. 1,234 × 5)
Type 3: 3-digit × 2-digit (e.g. 124 × 23)

All three use the same column method — just more rows for Type 3.
The golden rule — right to left, carry the tens
Always start multiplying from the ones column (right side) and work left. If a product is 10 or more, write the ones digit in the answer row and write the carry digit below the answer line in the next column — then add it at the very end.
Type 1 — 3-digit × 1-digit
Multiply each digit by the single digit, right to left. Carry when needed.
345 × 6

Step 1: 5 × 6 = 30 → write 0 in the answer, write carry 3 below the line
Step 2: 4 × 6 = 24 → write 4 in the answer, write carry 2 below the line
Step 3: 3 × 6 = 18 → write 8 in the answer, write carry 1 below the line
Now add the carry row: ones=0, tens 0+3=3 (but wait — we wrote 0 from 30, carry was 3. Let's redo cleanly):
Best method: multiply ALL digits first writing just the ones digit each time, write all carries below as a small row, then add that carry row to the answer.
5×6 ones digit=0, tens digit=3 (carry). 4×6 ones digit=4, tens digit=2 (carry). 3×6=18 ones=8, tens=1 (carry).
Answer row: _ 8 4 0. Carry row: 1 2 3 _. Add columns right to left: 0, 4+3=7, 8+2=10 (write 0 carry 1), 1+1=2.

Answer: 2,070

Type 2 — 4-digit × 1-digit
Exactly the same as Type 1 — just one extra digit to multiply. Still go right to left.
1,234 × 5

Multiply each digit × 5 right to left, writing carries below the answer line:
4 × 5 = 20 → write 0, carry 2 below
3 × 5 = 15 → write 5, carry 1 below
2 × 5 = 10 → write 0, carry 1 below
1 × 5 = 5 → write 5
Now add the carry row: 5+1=6, 0+1=1, 5+2=7, 0 stays 0

Answer: 6,170

Type 3 — 3-digit × 2-digit (long multiplication)
Split the 2-digit number into ones and tens. Multiply twice and add the results.
124 × 23

Row 1: 124 × 3 (the ones digit) = 372
Row 2: 124 × 20 (the tens digit × 10) = 2,480
  → write 0 as placeholder, then do 124 × 2 = 248

Add the rows: 372 + 2,480 = 2,852

Don't forget the placeholder zero!
When multiplying by the tens digit, always write a 0 in the ones column of that row first. This shifts the answer one place to the left.
Bigger 3-digit × 2-digit example
Let's try 456 × 78 — the numbers in the quiz that look most daunting. Same method, just bigger carries.
456 × 78
