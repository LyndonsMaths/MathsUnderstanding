First — know your three comparison symbols
When we compare two numbers we use one of three symbols to show the relationship between them.

>
Greater than
7 > 3
"7 is greater than 3"
=
Equal to
5 = 5
"5 equals 5"
🐊 The Crocodile trick
The crocodile always opens its mouth toward the bigger number — it wants to eat the larger one!
456,320 > 456,230 — the open end of > faces the bigger number (456,320).
How to compare two big numbers — go column by column
Step 1: Line both numbers up in a place value table.
Step 2: Start from the leftmost column (millions) and scan right.
Step 3: The first column where the digits differ — that column decides which is bigger.

Ordering three or more numbers — same method, repeated
Compare pairs of numbers using the column-by-column method. Then arrange them all from smallest to largest (ascending) or largest to smallest (descending).
Order from smallest to largest: 500,550 — 505,050 — 550,000
Line them up: all start with 5 in the HTh column.
TTh column: 500,550 → 0, 505,050 → 0, 550,000 → 5
∴ 550,000 is the biggest. Remove it.

Now compare 500,550 and 505,050:
TTh column: both 0. Th column: 500,550 → 0, 505,050 → 5
∴ 505,050 > 500,550

Order: 500,550 → 505,050 → 550,000 ✓
Tip: count the digits first!
A number with more digits is always bigger. 1,000,000 (7 digits) > 999,999 (6 digits). If they have the same number of digits, then compare column by column.
Two tricky question types from the test
Watch out for these — they need a slightly different approach.
True or False: 741,082 > 741,802
Line them up — HTh, TTh, Th columns all match (7,4,1).
Hundreds column: 741,082 → 0, 741,802 → 8
8 > 0 so 741,802 > 741,082. The statement is FALSE. ✓
Which number fits exactly midway between 400,000 and 600,000?
Midpoint = (400,000 + 600,000) ÷ 2 = 1,000,000 ÷ 2 = 500,000 ✓

Shortcut: Find the halfway point by adding the two numbers and halving, OR just find the number that is the same distance from each end.
Midpoint shortcut
Midway between A and B = (A + B) ÷ 2
Between 400,000 and 600,000: (400,000 + 600,000) ÷ 2 = 500,000
