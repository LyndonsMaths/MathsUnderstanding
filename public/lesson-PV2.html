Tell the Place Value of a Digit

PV2 · Numbers to 1,000,000 · NZ Year 6

Every digit has two things: its face value and its place value
The face value is just the digit itself — the number you see.
The place value is what that digit is actually worth because of where it sits.

The digit 5 by itself is just five. But in 456,123 the 5 sits in the ten-thousands column — so its place value is 50,000.
The digit 5 is in the ten-thousands column. 5 × 10,000 = 50,000.

Three steps to find the place value of any digit
Step 1: Write the number into the place value table.
Step 2: Find the digit you are looking for.
Step 3: Multiply the digit by its column value.

Watch out — two tricky question types
Some questions ask the value of a digit. Others ask which digit is in a named column, or how many of a unit there are. They look different but use the same table!
Question type 1 — "Which digit is in the hundred-thousands place of 907,342?"
Find the hundred-thousands column → the digit there is 9 ✓
Question type 2 — "In 865,000, how many ten thousands are there?"
Find the ten-thousands column → digit is 6, so there are 6 ten-thousands ✓
Note: "how many" means you just read the digit — you don't multiply!
Question type 3 — "In 134,567, what column does the 4 hold?"
Slot 134,567 into the table → 4 sits in the thousands column ✓
The place value table is your best tool — always use it!
Write each digit into its column first, then answer the question. It takes 5 seconds and prevents mistakes.
