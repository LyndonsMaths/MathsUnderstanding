Add Whole Numbers with More Than 4 Digits

AS1 · Addition & Subtraction · NZ Year 6

Column addition — line up the digits, then add right to left
When adding big numbers, write them in columns so the ones are above ones, tens above tens, and so on. Then add each column starting from the right (ones) and work left.

The golden rule — always start from the ONES column
Right to left: Ones → Tens → Hundreds → Thousands → Ten-thousands → Hundred-thousands
If a column adds up to 10 or more, write the ones digit and carry the tens digit to the next column.
Carrying — what to do when a column adds up to 10 or more
When two digits add up to 10+, you write the ones digit of the answer in that column and carry the tens digit into the next column to the left.
98,765 + 45,678 — multiple carries
Ones: 5 + 8 = 13 → write 3, carry 1
Tens: 6 + 7 + 1(carry) = 14 → write 4, carry 1
Hundreds: 7 + 6 + 1(carry) = 14 → write 4, carry 1
Thousands: 8 + 5 + 1(carry) = 14 → write 4, carry 1
Ten-thousands: 9 + 4 + 1(carry) = 14 → write 4, carry 1
Hundred-thousands: 0 + 0 + 1(carry) = 1
Answer: 144,443
Always write the carry digit small above the next column!
Write it lightly above the next column before you add that column — it's easy to forget a carry if you don't write it down.
Special case — when the answer is exactly 1,000,000
Sometimes two numbers add to exactly 1,000,000. This happens when each column adds to exactly 10 with carries all the way through. Watch for pairs that sum to round numbers!
678,900 + 321,100 = 1,000,000
Ones: 0 + 0 = 0
Tens: 0 + 0 = 0
Hundreds: 9 + 1 = 10 → write 0, carry 1
Thousands: 8 + 1 + 1(carry) = 10 → write 0, carry 1
Ten-thousands: 7 + 2 + 1(carry) = 10 → write 0, carry 1
Hundred-thousands: 6 + 3 + 1(carry) = 10 → write 0, carry 1
Millions: 0 + 0 + 1(carry) = 1
Answer: 1,000,000 ✓
Quick check — do the numbers add to a round number?
305,421 + 194,579 → notice 421 + 579 = 1,000 and 305 + 194 = 499... → 499,000 + 1,000 = 500,000
Always estimate first: 300,000 + 200,000 ≈ 500,000 — does your answer make sense?
